# SleepPath · Estratificación y abordaje del sueño

Prototipo educativo y de investigación para explorar patrones de sueño, clasificar necesidades de evaluación clínica y orientar opciones de abordaje de acuerdo con señales de insomnio, irregularidad, somnolencia y sospecha de apnea.

**Aplicación web (GitHub Pages):** https://roca148.github.io/Evaluacion-de-Organizaciones-de-Salud-Orientadas-a-IA/sleeppath/

**Archivo HTML:** [index.html](./index.html)  
**Investigación / Google Colab:** [SleepPath_Colab_pipeline_investigacion_v0.ipynb](./SleepPath_Colab_pipeline_investigacion_v0.ipynb)

## Alcance y limitaciones

- Puntuación 0–100 y agrupaciones basadas en **reglas heurísticas, no validadas prospectivamente**.
- No estima probabilidades clínicas de ictus, infarto, mortalidad u otros desenlaces.
- No reemplaza diagnóstico, polisomnografía ni valoración por personal sanitario.
- El cuaderno utiliza inicialmente **datos sintéticos** para demostrar un pipeline analítico. No es una herramienta clínica validada.
- No subir datos personales identificables de pacientes a repositorios públicos.

Investigación de referencia: [Nature Communications (2026)](https://doi.org/10.1038/s41467-026-75326-9).
